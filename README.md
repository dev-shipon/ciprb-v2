# CIPRB - Official Website

Centre for Injury Prevention and Research, Bangladesh (CIPRB) official website frontend project.

## Features
- Modern Responsive Layout built with Tailwind CSS & Vanilla JavaScript
- Animated Hero Slider featuring CIPRB research & field programs
- Public Health Domains & Innovations Showcase
- Optimized for mobile, tablet, and desktop viewports

## Local Development
To run locally:
```bash
python -m http.server 8000
```
Open `http://localhost:8000` in your web browser.
